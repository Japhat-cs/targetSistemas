# Desafio Target Sistemas 🚀
## Resolução de Exercícios Técnicos

Este repositório contém as soluções desenvolvidas para o teste técnico da **Target Sistemas**, utilizando a linguagem **Python**.

### 📋 Exercícios Resolvidos
- **Exercício 2**: Verificação de sequência de Fibonacci.
- **Exercício 3**: Análise de faturamento diário (processamento de JSON).
- **Exercício 4**: Percentual de representação por estado.
- **Exercício 5**: Inversão de caracteres de uma string sem funções prontas.

### 🛠️ Tecnologias
- **Python 3.x**
- **JSON**: Manipulação de dados estruturados para o exercício 3.
